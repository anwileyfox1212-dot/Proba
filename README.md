# КИМ БАО — сайт ресторана корейского стрит-фуда с онлайн-заказом

Полноценный работающий сайт: меню, корзина, регистрация и вход клиентов, оформление
заказа, отслеживание статуса и защищённая админ-панель. Собственная Motion Design-система
(preloader, кинематографичный hero, parallax, scroll-анимации, парящие блюда, переходы страниц).

**Нулевые внешние зависимости.** Всё работает на чистом Node.js и ванильном JS — никаких
платных сервисов, CDN, баз данных-серверов и сборщиков.

## 1. Требования

| Что | Версия |
| --- | --- |
| Node.js | 18 или новее (рекомендуется 20+ LTS) |
| npm | входит в состав Node.js |

```bash

```

Если Node.js не установлен, скачайте LTS-версию с https://nodejs.org и установите с параметрами по умолчанию.

## 2. Установка и запуск на Windows (пошагово)

1. Скачайте ZIP репозитория (кнопка **Code → Download ZIP**) и распакуйте, например в `C:\kimbao`.
2. Откройте папку проекта в Проводнике, в адресной строке наберите `cmd` и нажмите Enter
   (откроется командная строка уже в нужной папке). Или вручную:

   ```bash
   cd C:\kimbao
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

   Внешних пакетов нет, поэтому команда выполняется мгновенно и работает даже без интернета.

4. Запустите сайт:

   ```bash
   npm run dev
   ```

5. Откройте в браузере:

   **http://localhost:3000**

Остановить сервер — `Ctrl + C` в консоли.

### Если порт 3000 занят

```bash
set PORT=4000 && npm run dev
```

(в PowerShell: `$env:PORT=4000; npm run dev`)

## 5. Функции сайта

### Главная (`/`)
- прелоадер «КИМ БАО» с прогрессом загрузки;
- кинематографичный hero с кинетической типографикой и парящими блюдами;
- parallax-слои, бегущая строка, блок хитов, шаги заказа, преимущества;
- scroll-driven появление секций и stagger-анимации.

### Меню (`/menu`)
- 12 блюд в 4 категориях: Бао и бургеры, Уличная классика, Лапша и рис, Напитки и десерты;
- карточка: изображение (SVG-арт, генерируется локально), название, описание, состав, вес, цена, теги (хит / острое / веган);
- выбор количества и добавление в корзину с анимацией полёта блюда в корзину;
- фильтр по категориям и поиск по названию/ингредиентам;
- hover-анимации и 3D-tilt карточек.

### Корзина (drawer в шапке)
- анимированное открытие панели;
- изменение количества, удаление товаров;
- сумма блюд, доставка 190 ₽ (бесплатно от 1 500 ₽), итог;
- корзина сохраняется в localStorage и не теряется при перезагрузке.

### Клиент
- регистрация по логину/паролю и авторизация (`/auth`);
- пароли хранятся только в виде PBKDF2-хеша с солью;
- личный кабинет (`/account`): редактирование имени/телефона/адреса, активные заказы, история заказов;
- оформление заказа (`/checkout`): имя, телефон, адрес, комментарий, оплата наличными/картой;
- страница заказа (`/order/<id>`): трекер статуса, состав, суммы, данные доставки, история смены статусов.

### Статусы заказа

```
Новый → Принят → Готовится → Готов → Передан в доставку → Выполнен
```

Дополнительно: **Отклонён** (с причиной от администратора).

### Админ-панель (`/admin`)
- статистика: новые заказы, заказы в работе, всего заказов, выручка, клиенты;
- вкладка «Активные заказы»: состав, суммы, данные клиента, способ оплаты, комментарий;
- кнопки «Принять» / «Отклонить» (с указанием причины) и перевод заказа на любой статус;
- вкладка «История»: выполненные и отклонённые заказы;
- вкладка «Пользователи»: логин, имя, телефон, роль, количество заказов, сумма, дата регистрации;
- **защита**: все маршруты `/api/admin/*` требуют токена с ролью `admin` — обычный пользователь
  получает 403, а страница `/admin` показывает экран «Доступ только для администратора».

### Motion Design-система
Единые токены длительности и easing в CSS-переменных + один модуль `public/js/motion.js`:
preloader, занавес перехода страниц, reveal/stagger на IntersectionObserver, parallax и tilt на
requestAnimationFrame, полёт блюда в корзину, тосты, микроанимации кнопок.
Анимации используют только `transform`/`opacity`, автоматически облегчаются на тач-устройствах
и полностью отключаются при `prefers-reduced-motion: reduce`.

## 7. База данных

Локальное JSON-хранилище `server/data/db.json` — создаётся автоматически при первом запуске
(вместе с аккаунтом администратора). Схема описана в `server/schema.json`:

- `users` — `id`, `login`, `name`, `phone`, `address`, `role` (`user` | `admin`), `passwordHash`, `createdAt`;
- `orders` — `id`, `number`, `userId`, `items[]`, `subtotal`, `delivery`, `total`, `customer`, `payment`,
  `status`, `rejectReason`, `history[]`, `createdAt`, `updatedAt`;
- `sessions` — `token`, `userId`, `createdAt` (срок жизни 30 дней);
- `counters` — счётчик номеров заказов.

Сбросить все данные — удалите файл `server/data/db.json` и перезапустите сервер.

## 8. API (кратко)

Авторизация — заголовок `Authorization: Bearer <token>`.

| Метод | Маршрут | Описание |
| --- | --- | --- |
| GET | `/api/menu` | категории, блюда, условия доставки |
| POST | `/api/auth/register` | регистрация |
| POST | `/api/auth/login` | вход |
| POST | `/api/auth/logout` | выход |
| GET | `/api/auth/me` | текущий пользователь |
| POST | `/api/auth/profile` | обновление профиля |
| POST | `/api/orders` | создание заказа |
| GET | `/api/orders` | свои заказы |
| GET | `/api/orders/:idOrNumber` | отслеживание заказа |
| GET | `/api/admin/orders` | все заказы (только админ) |
| POST | `/api/admin/orders/:id/status` | смена статуса (только админ) |
| GET | `/api/admin/users` | пользователи (только админ) |
| GET | `/api/admin/stats` | статистика (только админ) |

## 10. Частые вопросы

**«npm не распознан как команда»** — Node.js не установлен или не добавлен в PATH: переустановите
Node.js и переоткройте консоль.

**Сайт не открывается** — проверьте, что в консоли видно «КИМ БАО — сервер запущен» и нет
ошибки о занятом порте.

**Забыли пароль клиента** — зарегистрируйте нового пользователя или удалите `server/data/db.json`.

**Корзина пустая после обновления браузера** — проверьте, что не включён режим инкогнито
(корзина хранится в localStorage).
